# Music Playlist Manager - Project Statement

## Problem Statement

Managing songs, playlists and favorite songs manually can be difficult when the number of songs increases. It can become difficult to keep track of songs and playlists in an organized way.

The purpose of this project is to create a simple Music Playlist Manager using Python. The system allows users to manage songs, create playlists, add or remove songs from playlists, and manage favorite songs.

The project also stores the data in a JSON file so that the data can be used again when the program is reopened.

---

## Scope of the Project

The project focuses on basic music playlist management.

The system allows the user to:

- Add and remove songs
- View and search songs
- Create and delete playlists
- Add and remove songs from playlists
- View playlists
- Shuffle playlists
- Add and remove favorite songs
- View favorite songs
- Save and load data using a JSON file

The project is designed as a simple menu-driven Python application.

---

## Target Users

The target users of this project are:

- Users who want to manage their songs
- Users who want to create and manage playlists
- Users who want to keep a list of favorite songs
- Students who want a simple music management application

---

## High-Level Features

The main features of the system are:

### 1. Song Management

Users can add, remove, view and search songs.

### 2. Playlist Management

Users can create and delete playlists and add or remove songs from playlists.

### 3. Favorite Management

Users can add songs to favorites, remove them and view their favorite songs.

### 4. Playlist Shuffle

Users can shuffle the songs inside a playlist.

### 5. Data Storage

The system stores songs, playlists and favorite songs in a JSON file.

### 6. Menu-Driven Interface

The system provides a menu through which users can select different operations.

---

## Project Objective

The main objective of this project is to create a simple and easy-to-use Python application for managing songs, playlists and favorite songs while using modular programming and JSON-based data storage.
